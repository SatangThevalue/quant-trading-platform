# 📘 คู่มือแนะนำการใช้งานแยกตามสินทรัพย์ (Asset-Specific Manual)

เอกสารฉบับนี้เจาะลึก **"คู่มือการใช้งานบอทเทรด"** แยกตามรายสินทรัพย์อย่างละเอียด เพื่อให้ผู้ใช้งาน (User) หรือ Fund Manager ทราบถึง "นิสัยของโมเดล" และวิธีการตั้งค่าให้ปลอดภัยที่สุด

---

## 🌟 1. EURUSD (ยูโร / ดอลลาร์สหรัฐ)
*คู่เงินที่มีสภาพคล่องสูงสุดในโลก เหมาะกับการเทรดเก็บรอบระหว่างวัน (Intraday)*

- **สถานะ:** 🟢 พร้อมรัน (Ready for Production)
- **EA ที่ต้องใช้:** `QuantTrader_ONNX_V2.mq5`
- **ไฟล์ Model (AI):** `models/production/EURUSD_model_v2.0_1h.onnx`
- **Timeframe บน MT5:** บังคับ **H1 (1 ชั่วโมง)** เท่านั้น
- **หลักการทำงานของ AI:** 
  - AI เรียนรู้จากระยะห่างของเส้น EMA 50 และ EMA 200 (EMA Gap) เพื่อหาจังหวะที่กราฟพักตัว (Pullback) แล้วยิงออเดอร์ตามเทรนด์ใหญ่
- **การตั้งค่าที่แนะนำ (Inputs):**
  - `Buy Threshold`: 0.65 (AI ต้องมั่นใจเกิน 65% ถึงจะซื้อ)
  - `Sell Threshold`: 0.35 (AI ต้องมั่นใจเกิน 65% ในขาลงถึงจะขาย)
- **ข้อควรระวัง:** สเปรด (Spread) มีผลสูง ควรใช้บัญชีประเภท **Raw Spread / Zero Spread** ของโบรคเกอร์ในการเทรดคู่นี้

---

## 🟢 2. USDCHF (ดอลลาร์สหรัฐ / ฟรังก์สวิส)
*คู่เงินสายปลอดภัย วิ่งในกรอบแคบและมักจะสะท้อนกลับ (Mean Reversion) ได้ดีที่สุด*

- **สถานะ:** 🟢 พร้อมรัน (Ready for Production)
- **EA ที่ต้องใช้:** `QuantTrader_ONNX_V2.mq5`
- **ไฟล์ Model (AI):** `models/production/USDCHF_model_v1.0_1d.onnx`
- **Timeframe บน MT5:** บังคับ **D1 (รายวัน)** หรือ **H4 (4 ชั่วโมง)** 
- **หลักการทำงานของ AI:**
  - AI ไม่สนใจเทรนด์ แต่มันจับตาดู **"ไส้เทียน (Shadows)"** หากมีแรงทุบลงมาทำไส้เทียนยาวๆ ด้านล่าง AI จะมองว่ารายใหญ่สลัดเม่า และจะเข้า Buy สวนทันที
- **การตั้งค่าที่แนะนำ (Inputs):**
  - `Buy Threshold`: 0.60
  - `Sell Threshold`: 0.40
- **ข้อควรระวัง:** จำนวนออเดอร์จะ **"น้อยมาก"** (อาจจะเทรดแค่ 1-2 สัปดาห์ต่อครั้ง) ผู้ใช้ห้ามตกใจแล้วไปบังคับเปิดออเดอร์เองเด็ดขาด ปล่อยให้ AI ทำงานไปอย่างช้าๆ แต่มั่นคง

## 🟡 3. GBPUSD & USDJPY (สายเหวี่ยงและโดนแทรกแซง)
*คู่เงินปราบเซียนที่มักจะโดนข่าวดอกเบี้ยหรือธนาคารกลางปั่นราคา*

- **สถานะ:** 🟡 ใช้งานได้ แต่มีข้อจำกัดสูง (Trade with Strict Limits)
- **EA ที่ต้องใช้:** `QuantTrader_Asian_Ranger.mq5` *(อยู่ระหว่างทดสอบเบต้า)*
- **Timeframe บน MT5:** บังคับ **H4 (4 ชั่วโมง)** เท่านั้น
- **หลักการทำงานของ AI:**
  - ถ้าเทรดบน H1 หรือ 15m จะโดนสัญญาณหลอก AI ของเราจึงรอดเฉพาะบนกราฟ 4 ชั่วโมงที่ดูเทรนด์ใหญ่จริงๆ
- **ข้อควรระวัง:** ห้ามรัน EA ปกติเด็ดขาด ต้องรอให้ผู้พัฒนานำระบบ **Macro API Gateway** (การต่อ API ดูดข้อมูลพันธบัตรสหรัฐ) เข้ามาเสียบในตัว EA ก่อน มิฉะนั้นโมเดลจะขาดทุนจาก Whipsaw

## 🔴 4. GOLD (XAUUSD) & BTCUSD (Bitcoin)
*สินทรัพย์อารมณ์รุนแรง (Sentiment-Driven) วิ่งตามข่าวและล้างพอร์ตเก่งที่สุด*

- **สถานะ:** 🔴 **ห้ามใช้งาน (Strictly DO NOT TRADE)**
- **เหตุผลทางการวิจัย:**
  - การใช้ Indicator พื้นฐาน (Price Action) ไม่สามารถเอาชนะทองคำและคริปโตในยุคนี้ได้
  - **GOLD:** จากการทำ Backtest โมเดลแพ้ค่า Spread และข่าวสงครามจนพอร์ตแหว่งเกิน -70% หากจะรันทองคำ ต้องรออัปเกรด EA ให้มีระบบ **"หยุดเทรดก่อนข่าวแดง ForexFactory"** (News API)
  - **BTCUSD:** โดนลากไปกิน Stop Loss ก่อนพุ่งจริง (Stop Hunt) เสมอ หากจะรันบิทคอยน์ ต้องรอการวิจัยโมเดลสาย Deep Learning (LSTM) และระบบ Sizing แบบแปรผกผันกับความผันผวน
